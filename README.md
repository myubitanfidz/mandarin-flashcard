# Mandarin Flashcard learning system

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![Laravel Version](https://img.shields.io/badge/Laravel-13.x-FF2D20?logo=laravel)](https://laravel.com)

**Mandarin Flashcard** adalah aplikasi untuk melakukan pembelajaran bahasa mandarin dengan interaktif dan mudah digunakan.


Proyek ini dibuat untuk siapa saja yang ingin mempelajari bahasa mandarin dengan lebih mudah secara mandiri dan **100% gratis** tanpa terkendala biaya.
